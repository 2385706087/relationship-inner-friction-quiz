# 关系内耗小测试

## 使用方式

直接用浏览器打开 `index.html`，或在本目录启动静态服务器：

```powershell
python -m http.server 8765
```

然后访问 `http://127.0.0.1:8765/`。

## 测试逻辑

- 共 12 题，每题 4 个选项。
- 每个选项分别对应：关系猜测、自动自责、习惯讨好、边界模糊。
- 最终以累计次数最高的类型作为主要结果，次高类型作为第二倾向。
- 平分时按该类型在计分表中的稳定顺序决定，仅用于提供可重复结果。

## 内容边界

本测试只用于自我探索，不用于心理诊断，不判断关系中谁对谁错，也不能替代专业咨询。
